**Where Stories Take Shape**

An artistic website celebrating the delicate art of book folding and paper sculpture. NovelPaper transforms discarded books into breathtaking three-dimensional art, preserving stories while giving them new dimensions.

🌐 **[Live Demo](https://hostilian.github.io/novelpaper/)** (once deployed)

---

## ✨ Features

- 🎨 **Minimalist Design**: Clean, elegant interface that puts the art first
- 📱 **Fully Responsive**: Beautiful on all devices, from mobile to desktop  
- ♿ **Accessible**: Built with semantic HTML5 and ARIA best practices
- ⚡ **Fast & Lightweight**: Pure HTML/CSS/JS with zero dependencies (~38 KB total)
- 🎭 **Smooth Animations**: Thoughtful interactions that enhance the experience
- 🔒 **Secure**: No external dependencies, security-validated with CodeQL

## 🎯 Philosophy

NovelPaper embodies five core principles:

1. **Minimalism with Meaning** - Every fold serves a purpose
2. **Respect for the Written Word** - Transform with reverence, never destroy
3. **Transformation Through Patience** - True art cannot be rushed
4. **Beauty in Subtlety** - The quietest statements are often the most profound
5. **Sustainability Through Repurposing** - Giving new life to old books

## 🚀 Quick Start

### Option 1: View Locally (Simple)

```bash
# Clone the repository
git clone https://github.com/Hostilian/novelpaper.git
cd novelpaper

# Open in your browser
open index.html  # macOS
start index.html  # Windows
xdg-open index.html  # Linux
```

### Option 2: Use a Local Server (Recommended)

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

### Option 3: Deploy to GitHub Pages

1. Fork this repository
2. Go to Settings → Pages
3. Select "Deploy from a branch"
4. Choose `main` branch and `/ (root)` folder
5. Click Save
6. Your site will be available at `https://yourusername.github.io/novelpaper/`

## 🎨 Design System

### Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Warm Brown | `#8B7355` | Primary (aged paper) |
| Light Tan | `#C9B896` | Secondary (book pages) |
| Rich Brown | `#A67C52` | Accent (leather binding) |
| Soft Black | `#3A3A3A` | Text (printed text) |
| Off-White | `#FEFDFB` | Background (paper) |
