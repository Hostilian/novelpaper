# NovelPaper

**Where Stories Take Shape**

An artistic website celebrating the delicate art of book folding and paper sculpture.

## 🎨 About

NovelPaper celebrates the delicate intersection of literature and sculpture. Each folded page transforms discarded books into breathtaking art, preserving stories while giving them new dimensions. We honor the patience, precision, and poetry of book folding—an art form that whispers rather than shouts.

## 🌟 Features

- **Minimalist Design**: Clean, elegant interface that puts the art first
- **Responsive Layout**: Beautiful on all devices, from mobile to desktop
- **Smooth Animations**: Subtle, thoughtful interactions that enhance the experience
- **Accessibility**: Built with semantic HTML and ARIA best practices
- **Performance**: Optimized loading and smooth scrolling

## 🎯 Philosophy

### Minimalism with Meaning
Every fold serves a purpose. We embrace simplicity to let the art speak for itself.

### Respect for the Written Word
Books are treasures. We transform them with reverence, never destroying but reimagining.

### Transformation Through Patience
True art cannot be rushed. Each piece requires hours of careful work.

### Beauty in Subtlety
The most profound statements are often the quietest. Our work invites closer inspection.

### Sustainability Through Repurposing
Giving new life to old books is both ecological and poetic.

## 🚀 Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Hostilian/novelpaper.git
cd novelpaper
```

2. Open in your browser:
```bash
open index.html
```

Or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx http-server
```

3. Visit `http://localhost:8000` in your browser

### Development

No build process required! Just edit the files and refresh your browser.

- `index.html` - Structure and content
- `styles.css` - All styling and responsive design
- `script.js` - Interactive features
