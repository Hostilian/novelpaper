## Release Notes

### Version 1.0.0 - "First Fold"

The inaugural release of NovelPaper brings a complete, production-ready static website celebrating the art of book folding. Built with vanilla web technologies and zero dependencies, this release focuses on elegant design, accessibility, and performance.

**Highlights:**
- 🎨 Beautiful, minimalist design inspired by paper and books
- ♿ Fully accessible with ARIA labels and keyboard navigation
- 📱 Responsive across all devices
- ⚡ Optimized performance (~38 KB total)
- 🔒 Security-validated (CodeQL)
- 📖 Comprehensive documentation

**Philosophy:**
This release embodies the five core principles of NovelPaper:
1. Minimalism with Meaning
2. Respect for the Written Word
3. Transformation Through Patience
4. Beauty in Subtlety
5. Sustainability Through Repurposing
